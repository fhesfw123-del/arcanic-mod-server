# 🎮 Arcanic Mod Update Server

Сервер автоматического обновления модов для Flehka Launcher.

## 📦 Установка

```bash
npm install
```

## 🚀 Запуск

```bash
npm start
```

Сервер запустится на `http://localhost:3000`

## 📝 Использование

### Веб-интерфейс

1. Открой `http://localhost:3000` в браузере
2. Заполни форму:
   - **Название мода** (латиницей, например: `arcanic-visuals`)
   - **Версия** (например: `1.0.0`)
   - **JAR файл** — выбери файл мода
3. Нажми "Загрузить обновление"

### API

#### Получить список версий модов
```
GET /api/versions
```

Ответ:
```json
{
  "arcanic-visuals": {
    "version": "1.0.0",
    "filename": "arcanic-visuals-1.0.0.jar",
    "size": 123456,
    "date": "27.10.2026, 18:12"
  }
}
```

#### Скачать мод
```
GET /mods/arcanic-visuals-1.0.0.jar
```

## 🔧 Интеграция с лаунчером

В лаунчере добавь проверку обновлений:

```javascript
async function checkModUpdates() {
  const res = await fetch('http://localhost:3000/api/versions');
  const versions = await res.json();
  
  // Проверяй версии установленных модов
  // Если версия на сервере новее — скачивай обновление
}
```

## 📁 Структура

```
mod-update-server/
├── server.js           # Основной сервер
├── package.json        # Зависимости
├── versions.json       # База версий модов (создаётся автоматически)
└── mods/               # Папка с файлами модов (создаётся автоматически)
```

## 🌐 Развёртывание

Для публичного доступа:
1. Хостинг: Heroku, Railway, Render
2. Добавь переменную окружения `PORT`
3. Обнови URL в лаунчере на адрес сервера
